## How to Run This Stage

### Step 1: Check the generated interface

Open `gen/greet_grpc.pb.go` and look at the `GreetServiceServer` interface:

```go
type GreetServiceServer interface {
    Greet(context.Context, *GreetRequest) (*GreetResponse, error)
    mustEmbedUnimplementedGreetServiceServer()
}
```

This tells you exactly what your server struct must implement.

### Step 2: Understand the structure

The generated code provides:
- `pb.UnimplementedGreetServiceServer` — a fallback that returns "not implemented" for every method
- `pb.RegisterGreetServiceServer` — a function that wires your server to gRPC

Your job is to:
1. Define a struct that embeds `UnimplementedGreetServiceServer`
2. Implement the `Greet` method
3. Call `RegisterGreetServiceServer` in `main()`

### Step 3: Build and run

From the `stage-06-first-grpc-server/` directory:

```bash
go build -o /tmp/greet_server ./server/
/tmp/greet_server
```

You should see:

```
2026/09/05 12:00:00 Server listening on port 50051
```


## What Each Part Does

### `type GreetService struct { pb.UnimplementedGreetServiceServer }`

We embed `UnimplementedGreetServiceServer` instead of directly implementing the interface. This means:
- We only write handlers for the methods we actually want to implement
- Any method we forget returns a clear "not implemented" error
- When someone adds a new RPC method to the proto, our server won't crash — it will just return "not implemented"

### `func (s *GreetService) Greet(ctx context.Context, req *pb.GreetRequest) (*pb.GreetResponse, error)`

This is the actual business logic. The gRPC framework calls this function when a client sends a `GreetRequest`. We:
1. Extract the `name` field from the request
2. Log that we received it
3. Build a response string
4. Return the response

The marshalling/unmarshalling to/from binary Protobuf is handled **automatically** by the gRPC framework — we never touch it.

### `pb.RegisterGreetServiceServer(grpcServer, &GreetService{})`

This tells the gRPC framework: "when a client calls `Greet`, call our `(*GreetService).Greet` method." Without this call, the gRPC server would not know about our service.

## The Request Flow (One More Time)

Now that you have written the server, here is the complete picture:

```
Client:  client.Greet(ctx, &GreetRequest{Name: "Alice"})
              │
              │  (stub marshals request, sends over HTTP/2)
              ▼
Server:  gRPC framework receives the frame
              │
              │  (looks up method handler)
              ▼
         GreetService.Greet(ctx, req)
              │
              │  (you write this — extracts name, builds response)
              ▼
         return &GreetResponse{Result: "Hello, Alice!"}
              │
              │  (gRPC framework marshals response, sends back)
              ▼
Client:  receives response
```
