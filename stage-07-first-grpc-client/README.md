## What Each Part Does

### `grpc.NewClient(address, ...)` — Dialing the server

```go
conn, err := grpc.NewClient(address, grpc.WithTransportCredentials(insecure.NewCredentials()))
```

`grpc.NewClient` creates a connection to the server at the given address.

- `address` is `"localhost:50051"` — the same port the server listens on
- `grpc.WithTransportCredentials(insecure.NewCredentials())` tells gRPC to use an insecure connection (no TLS). In production you would use TLS credentials instead.

Note: `grpc.NewClient` does not block. It returns immediately. The actual TCP connection is established lazily on the first RPC call.

### `defer conn.Close()` — Cleaning up

We use `defer` to ensure the connection is closed when the function returns. This is important — every connection should be closed when you are done with it.

### `pb.NewGreetServiceClient(conn)` — Getting the stub

```go
client := pb.NewGreetServiceClient(conn)
```

This is the generated constructor from the `.proto` file. It takes a connection and returns a `GreetServiceClient` — an object that has the `Greet` method.

### `client.Greet(ctx, req)` — Calling the RPC

```go
resp, err := client.Greet(ctx, req)
```

This looks like a normal function call, but underneath:
1. The stub marshals `GreetRequest` to binary Protobuf
2. It sends the request over the gRPC channel (HTTP/2)
3. It waits for the response
4. It unmarshals the response back into a `GreetResponse`
5. It returns the result

You never see any of this network code.

### `context.WithTimeout` — Preventing infinite hangs

```go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()
```

If the server is down, `client.Greet` would hang forever without a timeout. By wrapping the context with a timeout, the call will fail after 5 seconds instead of blocking indefinitely.

## The Complete Request-Response Flow

This stage completes the full picture from Stage 03 and Stage 06.

Server-side (Stage 06):
  grpcServer.Serve(lis) waits for connections
  HTTP/2 request arrives
  GreetService.Greet(ctx, req) is called
  Logs: Received Greet request for: Alice
  Returns: &GreetResponse{Result: Hello, Alice!}

Client-side (Stage 07):
  grpc.NewClient - connect to server
  NewGreetServiceClient(conn) - get client stub
  client.Greet(ctx, req) - make the RPC call
    Logs: Connected to server at localhost:50051
    Sends request, receives response
  fmt.Println(resp.GetResult())
    Prints: Server says: Hello, Alice!
